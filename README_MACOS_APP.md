# Инструкция по сборке и запуску нативной версии (macOS App)

1. Сборка пакета:
   ```bash
   ./build.sh
   ```
2. Собранное приложение будет находиться в папке `dist/Речь в текст.app`.
3. Контрольная сумма SHA-256 записана в `dist/checksum.txt`.

Приложение запускается изолированно, открывает нативное окно и работает на локальном порту (127.0.0.1).
Функционал перевода намеренно не добавлялся в соответствии с требованиями.
