# Заметки о выпуске: Версия 1.3.1 (Release Notes)

Версия 1.3.1 приносит ряд улучшений пользовательского интерфейса и встроенную документацию для упрощения работы с приложением.

**Новое в этой версии:**
* **Загрузка файлов (File Upload):** Улучшенный интерфейс выбора и загрузки аудиофайлов.
* **Чек-лист для микрофона и BlackHole:** При первом запуске теперь отображается удобный чек-лист для настройки системного звука и микрофона, помогающий избежать проблем с правами доступа.
* **Встроенная офлайн-документация:** Полное руководство пользователя теперь доступно прямо в приложении без необходимости подключения к интернету.
* **Всплывающие подсказки кнопок (Tooltips):** Элементы интерфейса получили понятные подсказки при наведении.
* **Создание отчетов об ошибках (Bug-report workflow):** Встроенная функция для легкого сбора диагностических данных в случае сбоев и генерации отчетов для разработчиков.

**Конфиденциальность и безопасность:**
* **Полная конфиденциальность локальных данных (Local-data privacy):** Все вычисления (включая распознавание речи) выполняются исключительно на вашем Mac. Приложение не отправляет ваши аудиофайлы или тексты в облако.
* **Системные требования:** macOS 13.0 или новее. Для работы требуется Apple Silicon (M1/M2/M3/M4) или Intel Mac с поддержкой AVX2.

**Внимание (Требования Gatekeeper):**
Данная версия подписана локальным разработчиком (ad-hoc) и не проходила процедуру нотаризации Apple. 
Из-за этого при первом запуске (или извлечении из ZIP-архива) macOS Gatekeeper может показать предупреждение. 
Для запуска приложения перейдите в **Настройки системы -> Конфиденциальность и безопасность** (System Settings -> Privacy & Security) и разрешите открытие приложения "Речь в текст".

**Для разработчиков и QA:**
* Интегрированы и пройдены расширенные E2E тесты пользовательского интерфейса (pytest).
* Контрольная сумма ZIP-архива (SHA256) верифицирована. 
* Соблюдены известные границы нативного тестирования приложения.
