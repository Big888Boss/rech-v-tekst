Создание конспекта

Конспект формируется на основе распознанного текста вебинара с помощью изолированного CLI Claude. Проверьте параметры и подтвердите согласие на передачу.

⚠️ Предупреждение о конфиденциальности

Использование внешнего CLI передаёт текст расшифровки выбранному сервису. Флаг --tools "" блокирует вызов локальных инструментов, однако режим --bare требует явной конфигурации API-ключа.

«Отмена»: закрыть окно без отправки запроса. «Сгенерировать конспект»: требует подтверждения согласия выше; отправляет расшифровку в Claude CLI.

Убрать запись из очереди

Запись — будет исключена из активной очереди ожидания.

ℹ️ Исходные файлы сохраняются

Исходный аудиофайл, фрагменты и расшифровки остаются на диске и не удаляются. Вы сможете вернуть запись в очередь в любой момент, выбрав фильтр «Убранные из очереди».

«Отмена»: закрыть окно и оставить запись в очереди. «Убрать из очереди»: исключить из очереди с сохранением всех файлов на диске.
